# Security policy

## Supported version

Only the `main` branch is supported.

## Report a vulnerability privately

Do not open a public issue for a security problem. In the `deakR/cold-harbour` repository, open **Security** and use **Report a vulnerability** or **Security Advisories** to contact the maintainers privately.

Include the affected version or commit, the impact, and the steps needed to reproduce the problem. Do not include real credentials, personal data, customer data, or production logs.

## Do not post publicly

Do not post exploit details, working proofs of concept, leaked secrets, personal data, or unfixed vulnerability reports in issues, discussions, pull requests, or chat. Wait for a maintainer response before disclosing the issue.
